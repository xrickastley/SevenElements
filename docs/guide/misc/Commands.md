# Commands

Commands, also known as **console commands** or **slash commands**, are a mechanic that execute specific actions when entered as text or triggered by blocks or [entities](https://minecraft.wiki/w/Entities).

### List of commands

- [`/element`](./Commands/element.md)
- [`/bossbar`](./Commands/bossbar.md)
