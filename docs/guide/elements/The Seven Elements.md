# The Seven Elements

In Genshin Impact *and* **Seven Elements**, there exists the seven Elements: <span class="pyro">**Pyro**</span>, <span class="hydro">**Hydro**</span>, <span class="anemo">**Anemo**</span>, <span class="electro">**Electro**</span>, <span class="dendro">**Dendro**</span>, <span class="cryo">**Cryo**</span>, and <span class="geo">**Geo**</span>.

By combining specific elements together, you're able to trigger [Elemental Reactions](./Elemental%20Reactions.md)! Each element is its own damage type, and non-elemental damage is considered **Physical**, which isn't an element.

When applying an element to an entity, it will decay over time, so there isn't any concept of "infinite elemental application"!

## Elemental Combat

&nbsp; &nbsp; *Main page: [Elemental Combat](./Elemental%20Combat.md)*

In Seven Elements, you may infuse your attacks with one of the seven Elements and deal Elemental Damage of that element.

## Elemental Reactions

&nbsp; &nbsp; *Main page: [Elemental Reactions](./Elemental%20Reactions.md)*

When applying an element on a target already afflicted with an element, various Elemental Reactions may be triggered.

## Elemental Application Systems

&nbsp; &nbsp; *See also: [Elemental Gauge Theory](./Elemental%20Gauge%20Theory.md) and [Internal Cooldown](./Internal%20Cooldown.md)*

Elements aren't just a state of *applied* or *removed*, they are rather represented as a certain amount of *[gauge units](./Elemental%20Gauge%20Theory.md#elemental-auras-and-the-aura-tax)*. Elements can also only be applied in certain intervals, where elemental damage dealt within the interval *only* deals elemental damage but does not apply an Element.
