Dendro Attunement Smithing Template ​

A dendro attunement smithing template is a type of elemental attunement smithing template used in smithing tables that can be used to add an elemental attunement to weapons or armor. It is consumed when used, but can be duplicated using an existing template and an elemental rune.

Obtaining ​

A dendro attunement smithing template can be obtained by aligning an elemental attunement smithing template to Dendro. Once obtained, it can be duplicated using the crafting recipe below.

Elemental alignment ​

An elemental attunement smithing template may be aligned to a dendro attunement smithing template by breaking nature-related blocks.

Usage ​

Crafting ingredient ​

It is an ingredient in its own recipe, making it possible to craft copies after the initial item is obtained.

2

Smithing ingredient ​

Using the smithing table, the dendro attunement smithing template can be applied to weapons and tools, using an elemental rune.
